## UI work

Before you add or change a component, a section, a style, a token, or copy on the page:
1. Read `docs/generated/llms.txt`, then `docs/generated/system/rules.md`, `docs/system/decisions.md` and the page in `docs/generated/system/` for each thing you touch.
2. If the task is in `docs/system/coverage-gaps.md`, follow that row's Meanwhile and name the gap in your final message.
3. Use a registry component (`registry.json`) and the tokens at the top of `app/globals.css`. Each token's comment says its job. If none fits, ask before adding one.
Before you finish: run `npm run check`, and look at the page at 390 and 1440 wide.
After editing anything in `docs/system/`, the token block or `registry.json`: run `npm run docs`.
This app is not the git root, so every `node scripts/...` command below needs `--root .` when run from `web/`, as in `node scripts/check-system.mjs --root . --explain <rule-id>`.
