One memory for all your agents.

Bravogram is a local memory that Claude, Hermes and any MCP agent share. They save what they learn, find it again in milliseconds, and you see all of it as a graph.

Node 24 or newer · zero dependencies · MIT license

What Bravogram does.

Four things an agent's memory has to get right, in one small tool.

Remember

Any agent saves a fact, a decision or a lesson with one call. Everything lives in a single file on your machine.

~/.bravogram/memory.db
$ bravogram remember "Ship on Fridays only
after the smoke test passes" --type decision
saved #24 Ship on Fridays only after the smoke…

Recall

Ranked full-text search that returns short snippets, not whole notes, so agents spend fewer tokens on every lookup.

bravogram recall "smoke test"
#24 Ship on Fridays only… [decision]
    …only after the smoke test passes
#11 release checklist [project]
    …run the smoke test against staging…

See the graph

Memories link to each other with [[wikilinks]]. One command opens them as a graph you can search and click through.

127.0.0.1:4747

Undo anything

Every change and every delete is kept. If an agent overwrites a note, one command brings the old version back.

bravogram history roadmap
roadmap: current #9, 1,231 chars
  rev 3  10-03 15:22  update  by claude-code
  rev 2  10-03 14:10  update  by hermes
$ bravogram restore roadmap --rev 2

Three commands to a shared memory.

Install it. One global package, nothing else to set up.

npm i -g bravogram

Connect your agents. Any MCP client uses the same command. Agents get five tools: recall, remember, append, show and link. Only you can delete.

claude mcp add --scope user bravogram -- bravogram mcp

Look at what they know. Bring in an existing Obsidian vault if you have one, then open the graph.

bravogram import ~/notes && bravogram graph

Common questions.

Where does my data live?

In one SQLite file at ~/.bravogram/memory.db on your own computer. Nothing is sent anywhere. There are no accounts and no telemetry.

Which agents work with it?

Anything that speaks MCP, and anything that can run a shell command. It is tested with Claude Code. Each memory records which agent wrote it.

Can two agents write at the same time?

Yes. Writes take turns under a lock, so one agent can't overwrite another's work halfway through. This is covered by the test suite.

Is it a replacement for Obsidian?

For agents, yes: it imports a vault and can export back to Markdown. For you writing long notes by hand, Obsidian is still the better editor.

What doesn't it do yet?

Search is keyword based, so it won't match by meaning. There is no sync between machines. The graph page loads its drawing library from a CDN, so it needs a connection the first time. It's version 0.1.

What does it cost?

Nothing. It's MIT licensed and the code is on GitHub.
